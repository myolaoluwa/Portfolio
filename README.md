# DelighTech Website

Official portfolio and studio website for [DelighTech](https://www.delightech.net/), a software studio building web applications, mobile products, SaaS/MVP solutions, and AI-assisted workflows for teams worldwide.

## What this site presents

- DelighTech's software development services
- Selected products, portfolio work, and case studies
- Technical capabilities and delivery approach
- Clear ways for prospective clients to get in touch

## Technology

Built with Next.js, React, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.
